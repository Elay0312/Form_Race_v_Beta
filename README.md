# Гоночная игра на Pygame

Простая 2D гоночная игра с элементами управления мышью и клавиатурой. Игрок управляет машиной, избегая столкновений с встречным транспортом.

## 🚀 Особенности

- Управление автомобилем с помощью мыши (вертикальное перемещение)
- Динамическая скорость движения фона (создаёт эффект движения)
- Система ускорения и торможения
- Отслеживание времени и пройденного расстояния
- Встречные автомобили-соперники
- Победа при преодолении 100 км

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| `Left Shift` | Газ (ускорение) |
| `Space` | Тормоз |
| `Мышь` | Вертикальное перемещение машины |

- Python 3.x
